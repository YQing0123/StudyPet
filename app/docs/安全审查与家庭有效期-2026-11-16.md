# 公网安全审查、邀请码与家庭有效期

审查日期：2026-11-16。基于本地工作区代码、隔离数据库的真实 HTTP 测试、生产前端构建及后台浏览器检查。本次没有连接 NAS、修改生产数据或发布线上版本，也没有对公网域名或 NAS 其他服务执行扫描。

## 审查发现与本次修复

| 等级 | 发现 | 处理 |
| --- | --- | --- |
| 高 | `/api/auth/register` 可以不经审核直接创建账号和家庭，公网暴露后可被滥用 | 创建家庭必须兑换管理员签发的开通码；注册与兑换使用同一事务，失败整体回滚 |
| 中 | 配置公网 Origin 后仍允许按 Host 回退校验请求来源 | 公网模式只接受配置的 HTTPS Origin；无 Origin 的写操作检查 Referer；拒绝跨站写请求，保留外部审核导航和令牌照片读取 |
| 中 | 密码采用 scrypt 默认成本，且未限制并发昂贵计算 | 新散列使用 `N=16384,r=8,p=5`，每个任务约 16 MiB；全局最多 4 个散列任务。旧格式密码仍能登录，成功后自动升级；验证过程中凭据变更会拒绝旧请求 |
| 中 | 通用 JSON 接口统一允许 8 MiB，部分请求没有业务级限流 | 普通 JSON 上限 256 KiB，作业照片提交保留 8 MiB 上限；严格校验 JSON 对象和媒体类型；账号、身份、管理员及推送测试分别限流 |
| 中 | 缺少统一安全响应头，部分数据库错误可能返回表名 | 增加 CSP、防页面嵌入、防 MIME 嗅探、Referrer-Policy、Permissions-Policy；公网启用 HSTS；数据库错误改为通用提示 |
| 中 | 无家庭级服务端有效期控制 | 服务端统一阻断到期后的业务写入；请求体读取后再校验一次，避免慢请求跨越到期时间；读取不再生成新计划任务；每日汇总对到期家庭停发 |
| 加固 | HTTP 和容器资源限制 | 请求超时 30 秒、请求头超时 10 秒、限制头数和单连接请求数；容器增加进程数限制，继续保留非 root、只读文件系统、禁提权和资源限制 |

复查并保留的现有机制：服务端家庭/孩子归属验证、学生与家长权限区分、家长模式解锁、随机会话令牌及散列存储、修改密码/移除家长时撤销会话、参数化 SQL、停用旧 `/mcp` 和 `/media` 入口。推送地址仅允许官方固定 HTTPS 主机与路径，禁止重定向；接口不返回推送 Token 和加签密钥。

通过官方 npm registry 运行 `pnpm audit --registry=https://registry.npmjs.org --json`，本次已知漏洞数为 0（包含开发依赖）。这只说明本次依赖公告查询结果，并不表示系统不存在未知漏洞。

## 三类邀请码

| 类型 | 谁创建 | 用途 | 是否改变家庭有效期 |
| --- | --- | --- | --- |
| 家庭开通码 | 平台管理员 | 创建新家庭，包括尚未迁移的原家庭记录 | 从成功创建时开始计时 |
| 家庭续期码 | 平台管理员 | 已登录且已解锁的家长为当前家庭续期 | 未到期接在原期限后；已到期从兑换成功时开始 |
| 家长成员邀请码 | 当前家庭家长 | 邀请另一位家长加入已有家庭 | 不改变，所有家长和孩子共用家庭期限 |

开通码/续期码以 `BX-` 开头，包含 128 位随机值。每码仅可成功兑换一次；只保存规范化代码的 SHA-256 散列与尾号，完整码只在签发结果中显示，刷新后无法找回，可撤销后重新签发。管理员分别设置使用天数（1–3650 天）和兑换期限（1–365 天）。使用天数是连续 24 小时，不是自然月；逾期未兑换、已使用或已撤销均失效。

成员邀请码仍为 48 小时内一次性使用。它不能用于创建家庭或续期；到期家庭不能签发或兑换成员邀请。平台管理员会话与家庭会话分开，互相不能访问对方受保护的接口；平台没有公开的管理员注册接口。

## 管理员初始化与使用

先构建并部署包含本次源码的新镜像，保留原 `/data` 挂载和数据属主。在 NAS 的 Compose 项目目录运行：

```sh
docker compose exec app node scripts/admin-account.mjs island-admin
```

按提示输入两次至少 12 位的独立密码，终端不回显。不把密码写进命令行或聊天。重复执行同一账号会重设管理员密码并立即撤销该账号所有旧管理会话。命令必须在正确的容器/数据目录运行；不要在开发机默认数据目录里创建后误以为已初始化 NAS。

本地开发时可在 `app` 目录运行 `node scripts/admin-account.mjs island-admin`，如使用独立数据目录，须同时设置正确的 `BANXUE_DATA_DIR`。

随后访问站点 `/admin`：

1. 登录管理台，在“签发邀请码”选择新家庭开通或已有家庭续期，填写套餐名称、使用天数和兑换天数。
2. 保存本次显示的完整码，再通过自己的渠道发给用户。管理台不自动发送消息。
3. 用户在“创建家庭”中填写开通码；家长在“家庭管理”中填写续期码。
4. 管理员也可以搜索家庭名称或完整 ID，设置具体到期时间或不限期。每次修改必须填写原因；最近 50 次开通、续期和人工变更可在弹层内查看。
5. 管理会话有效 8 小时，家庭会话仍为 14 天。管理端退出立即撤销本会话。

首次升级时，已有家庭自动标记为“原有家庭 / 不限期”，保留全部记录和原权限。管理员可再为这些家庭指定套餐和期限；不会自动将现有用户停用。尚未关联的原型数据迁移同时要求有效开通码和原家长 PIN，不再能只靠原型默认 PIN 创建公网家庭。

## 到期行为和提醒

家长与学生页面均显示家庭有效期，家长的“家庭管理”显示套餐、准确到期时间和续期入口。页面按北京时间展示；到期前 7 天提示即将到期；到期时显示只读提醒。页面每分钟、重新获得焦点、接口返回到期状态时刷新会话；具体到期时间另设刷新计时器。服务端时间负责真正判定，客户端时间或页面刷新不能延长权限。

到期保留：登录/退出、锁定/解锁家长模式、切换有权限的家庭/孩子、查看历史数据、家庭成员和已有备份、修改自己的密码、重设已有学生密码、移除家长和撤销旧成员邀请，以及兑换续期码。管理员权限不依赖任何家庭订阅。

到期暂停：创建/修改计划、任务提交和审核、纸条、赠送星贝、心愿与材料兑换、宠物领养/互动/改名/升级/更换/重养、创建/恢复备份、通知设置/测试、添加孩子、开通新学生账号、邀请新家长。服务端返回 HTTP 402 和可读的续期提示；学生管理越权仍优先返回 403。续期后无需重新登录即可恢复写入，原学习、宠物、星贝和成员记录保留。

当前实现的是套餐有效期与人工续期，没有支付渠道、扣款、自动续费、发票、退款、到期短信/邮件或自动对外售卖。提醒目前是站内提醒；以后接支付时，应由服务端校验支付回调后在事务内增加有效期并保证幂等，不能信任前端付款结果。

## 部署配置与仍需核验的边界

- 公网生产模式要求 `NODE_ENV=production` 和有效的 `BANXUE_PUBLIC_ORIGIN=https://实际域名`（不含路径）；启用 Secure Cookie 和 HSTS。只有隔离内网 HTTP 试用才可将 Origin 留空并显式设 `BANXUE_ALLOW_HTTP=1`；公网不要开启该例外。
- 仅将应用站点提供给隧道入口。NAS 管理、SSH、Docker API、SQLite 和数据备份不得通过同一映射公开。应用代码审查不能证明当前路由器、防火墙或隧道实际配置正确，本次未远程核验这些配置。
- 对外开放前，建议在入口将 `/admin` 和 `/api/admin/` 限制为自己的可信网络或 VPN 访问。管理员密码与家庭密码分开设置；应用目前尚未接入管理员 MFA。
- 应用按真实 TCP 对端限流，不信任客户端随意填写的 `X-Forwarded-For`。穿透/反代共享同一对端时，登录 IP 配额也会共享；正式对外应在可信入口增加按真实来源的限流、连接数和上传限制。应用内限制不能替代公网流量防护。
- 推送凭据及孩子资料仍存本地 SQLite，照片仍在库中；保护 NAS 数据卷和备份权限，使用加密备份并验证恢复，避免将真实数据用于开发或公开分享。推送照片链接作为 7 天有效的随机令牌链接存在，接收链接的人在有效期内可读取该照片，应只发送到可信家庭群。
- 家长账号自助找回、管理端 MFA、集中监控、数据保留/删除策略和按家庭存储配额尚未实现。开放给外部用户前应按实际规模补齐；数据库膨胀和入口大流量攻击仍需运维措施。
- 生产发布前备份并停止写入后更新，运行数据库完整性检查，验证旧家庭、旧密码、已有宠物/任务/照片、管理员初始化和公网 HTTPS 登录。本次不自动发布到 NAS。
