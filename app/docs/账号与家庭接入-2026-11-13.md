# 家庭账号接入与体验优化 · 2026-11-13

已将原本机单用户入口改为账号 → 家庭成员 → 孩子的持久关系。每个家庭可有多个独立家长账号，家长共同管理全部孩子；每个孩子拥有独立计划、宠物、背包、星贝和审核记录，可开通仅访问自己的学生账号。家长账号可以通过邀请加入多个家庭。

## 使用

打开 http://127.0.0.1:7788 。首次选择「创建家庭」，填写自己的账号、至少8位密码及家庭名称，并输入原4位家长密码关联原记录。程序不会代设账号或删除原记录。以后用新账号密码登录；原4位密码只用于首次迁移。

顶部切换孩子；「家庭管理」添加孩子、开通/重设学生账号，或生成48小时有效、一次性的家长邀请码。另一位家长通过「加入家庭」建立自己的账号；已有家长账号可在家庭管理中加入其他家庭。邀请链接仅复制，由用户自行分享，程序未向任何人发消息。

家长回学生端时管理权限上锁，需要本人账号密码解锁。学生账号无法进入家长模式。重新开始当前孩子的小岛已移到家长设置，并需确认；其他孩子和家庭账号保留。

## 实现

- `server/accounts.mjs` 增加 family、user_account、family_member、login_session、family_invite、account_audit、auth_attempt 表，以及 child.family_id。迁移为增量执行。
- 密码使用异步 scrypt、随机盐、恒定时间比较；会话用随机token，数据库仅存SHA256。HttpOnly、SameSite=Strict；服务重启保留登录。改密撤销其他设备，重设学生密码与移除家长即时撤销会话。
- 每个请求验证账号、家庭成员及孩子归属。请求开始时固定家庭/孩子请求头，后端用 AsyncLocalStorage 贯穿业务，前端切换上下文重挂载业务页面，避免跨家庭、跨孩子串写。
- 审核与积分在事务内提交，双家长同时审核同一任务仅发一次星贝；成功业务写入记录操作账号、家庭、孩子及资源路径。
- 旧的未隔离教材/导入/MCP等原型接口返回410。当前产品学习计划、任务、宠物、商店和奖励接口均要求登录。
- Origin与JSON请求校验；登录/解锁/邀请限流；无默认账号密码。

## 性能与交互

- 视频纹理按 requestVideoFrameCallback 更新，兼容浏览器回退 requestAnimationFrame 并跳过重复画面。后台暂停、回前台恢复；保留失败姿态回退、睡眠终帧、动作中断和销毁清理。
- 静态媒体流式读取，支持Range/HEAD/ETag/304；缺失素材返回404。避免每个请求将整段媒体读入内存。
- 日历复用规则、批量汇总轻量任务字段，跳过已有任务生成。隔离样本20条规则、620项任务：数据库调用642→53，约10ms→3ms，非公网或并发性能承诺。
- 手机管理操作点击区至少44px；登录、创建家庭、家庭管理沿用暖纸、森林绿与现有Sheet。保存失败保留表单，支持恢复重试和刷新读回。
- 修复领养遮罩挡账号栏/家长解锁、家长刷新误进领养、日历请求后到先覆盖与静默失败等问题。

## 验证和证据

`npm run typecheck`、`npm test`（65项业务回归、17品种、28项家庭账号检查）。账号测试覆盖多家庭/多孩子隔离、学生越权、双家长审核、邀请码、改密与会话撤销、重启持久化和旧记录迁移。全部使用隔离库，未对真实库执行reset。

后台浏览器验证创建家庭、添加孩子、开学生账号、学生登录与领养、家长上锁/解锁；断网保留输入→恢复重试→刷新读回；1440×900、1024×768、768×1024、390×844布局。独立视觉与UX评审各一轮，已修复点击区和密码提示。

证据目录：工作区 `output/family-smooth-20261113/` 和 `output/playwright/family-smooth-20261113/`。

## 部署边界

当前仍是本机Node+SQLite服务，适合继续开发和本地验收；已实现服务端账号与租户权限，无需外部身份供应商。短信、邮箱验证/找回、设备管理界面尚未接外部服务。公网部署需实际HTTPS域名/反向代理及 `BANXUE_PUBLIC_ORIGIN=https://实际域名`（同时启用Secure Cookie），并配置备份与运维。没有把当前本机预览称为已完成公网部署。
