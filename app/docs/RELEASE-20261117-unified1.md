## 本次更新

- 大屏场景与宠物比例按可用场景面积平滑调整，最大放大 1.5 倍；睡眠状态额外补偿 1.3，减少高分辨率下的空场和宠物过小。
- 家长端小纸条铺满内容区；家长导航与 Tab 左对齐，返回学生端和积分入口右对齐。

- JSON 响应启用 gzip、ETag/304；带哈希的 JS/CSS 使用一年 immutable 缓存，HTML/JSON 保持重新验证。
