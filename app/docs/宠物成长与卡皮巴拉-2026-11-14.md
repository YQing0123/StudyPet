# 宠物成长外观与卡皮巴拉

本轮为卡通柯基接入六个年龄阶段的外观，并新增可领养、可更换的卡皮巴拉。当前共18个品种。入口是学生场景「宠物菜单 → 选择宠物」；家长端共用的品种选择器和首次领养也包含卡皮巴拉。

## 六阶段外观

| 阶段 | 外观 | 场景体型比例 |
| --- | --- | --- |
| 幼年 | 原始毛茸茸，圆头小身体 | 62% |
| 少年 | 鼠尾草绿领巾 | 80% |
| 青年 | 奶油色口袋马甲 | 92% |
| 成年 | 森林绿斗篷、橡果胸针 | 100% |
| 中年 | 深绿斗篷、金色星章 | 100% |
| 老年 | 暖杏色针织披肩、木扣 | 94% |

服饰已画进各年龄的动作素材，和身体一起运动、翻转、趴下，不使用悬浮Emoji代替成长服饰。材料铺购买的蝴蝶结/皇冠仍走既有独立装扮层，成长衣服不消耗库存，也不写入或覆盖购买的装扮。

年龄机制已由后续改造替换为六龄十二阶：自然时间与每日有效成长累计，达标后由孩子点击确认；详情见[宠物成长升级机制研究](宠物成长升级机制研究-2026-11-14.md)。跨年龄只在孩子点击后的光幕切换点换素材，同龄进阶增加常驻星章；原1/3/7/14/30天自动升级及物种年龄倍率已经停用。

选择器提供六年龄和九个日常动作预览，预览不写年龄。保存只提交品种，保留宠物ID、名字、领养日期、成长、背包、星贝和学习计划；实际年龄由服务器计算。小岛档案提供六阶段成长相册和下一阶段的陪伴天数。小房间预览单独缩小到舞台比例的68%，保持各年龄的大小差异，并避免成年外观头顶被裁切。

## 动作与制作来源

**当前卡皮巴拉素材版本为 `2026-11-15.capybara-motion-v3`，正式服务版本为 `2026.11.15-capybara3`。** 陪玩、抚摸及退出沿用v2单纹理骨架；走路更新为36帧/1.2秒与同步步幅。其余7动作已从两姿态RGBA混合改为“本机RIFE只计算几何、每帧单源采样”，处理嘴鼻双轮廓。下述初版与v2内容为制作历史，当前复现以本节命令为准。

按用户指定使用Image API CLI fallback，模型`gpt-image-2.6-sunburst`、quality high。保留现有卡通柯基作为参考，通过CLI `edit`制作11张2048×2048动作图集：柯基五个成长新外观，卡皮巴拉六个年龄。每张图集6列×8行，48个姿态；它们是静态生成图集，不是模型返回的原生GIF，也不是每只宠物独占2K分辨率。

8行分别为坐姿互动、走路、进食、抚摸、陪玩、自抱抱、睡下、伸懒腰。图集先按实际连通域恢复行列边界，避免模型行距偏移造成裁脚；洋红底抠像、边缘去色、统一地面和固定尺度后，用已有RIFE 4.25离线补中间帧，导出512×512、30fps VP9 alpha。没有把重复持有关键帧计作高帧率制作。

每套新外观提供11个视频键：`greet/walk/eat/eatrev/petted/petted-out/play/hug/sleep/wake/stretch`。抚摸和进食有独立退出片，醒来由睡下反向姿态推导，抱抱有自己的姿态行。六个PNG兼容键仍保留：`sit/walk/sleep/stretch/roll/jump`；roll/jump是取自陪玩/抱抱的回退姿态，没有宣称制作独立翻滚和跳跃视频。

原始幼年柯基保留已有v3动作，仅替换walk。其hug仍复用petted，stretch仍走已有静态回退。新增成长阶段和卡皮巴拉提供独立hug/stretch视频。

初版共输出122段新制/修复视频、6603帧。原始PNG和精确提示词保留在`output/imagegen/pet-growth-20261114/`，每套最终图集和提示词也复制进宠物包对应年龄的`source/`，该目录不发布到网页。生产报告记录源图、关键帧顺序、SHA256、帧数、时长和不同帧数。发布包位于`assets/pets/dog_corgi_toon/`和`assets/pets/capybara_toon/`；柯基继续使用`2026-11-14.growth-v1`，卡皮巴拉使用上方的动作修复版本。

## 柯基走路卡顿修复

原生walk九张姿态中，第4张之后出现尚未完成收腿就再次前伸的重复步序。原先补帧把错误步序平滑化，仍会在循环里显出一次滑步。修复使用原始已对齐姿态，按数组索引`[3,2,1,0,8,7]`整理成单次支撑→回收→前摆→落地的循环，再重新生成36帧/1.2秒。排除重复前伸的索引4、5、6，保留原始GIF和修前视频，记录在`source/walk-repair.json`。各成长外观也按单步顺序整理关键帧后补帧。

另外曾请求一张8姿态走路修正图集，但其后腿运动仍不充分，未采用；它仅作为试验记录留在output，不进入发布包。不能把这次未采用的图集称为最终walk来源。

## 卡皮巴拉动作重影修复 v2（历史）

初版的源姿态之间有腿长、脚的位置、遮挡和颜色差异。把这类姿态送入神经补帧，会在脚部合成半透明的过渡轮廓；六张源图也不能保证包含一整次步态。舞台原先按固定百分比速度移动身体，与脚的支撑速度没有关联，进一步产生滑脚。

修复保留原 `gpt-image-2.6-sunburst / high` 图集与六年龄衣服，不重新生成角色。四个动作分别从固定姿态提取纹理，连续变形时保持身体内部不透明，仅轮廓保留一像素抗锯齿。输出仍为 512×512、30fps VP9 alpha，采用 lossless 编码，不使用不同姿态的 RGBA 混合或 RIFE。

- 走路：四脚独立、四拍错相；每次完整周期 1.6 秒、48 帧，包含支撑后蹬、离地、前摆、落地。支撑占周期 68%，前后摆位置和速度在循环接点连续，至少两脚同时支撑。各脚支撑时相同的向后速度通过 `walk.gait` 元数据换算到实际渲染尺寸，舞台位移随年龄尺寸、播放速率和手机缩放同步。
- 陪玩：使用完整的伸爪姿态；玩具从同一图集的完整圆球提取，爪子小幅推球、球滚出并返回。后脚及支撑脚保持稳定，没有把抬爪后不存在的腹部当作矩形切掉。
- 抚摸：固定脚部，头颈轻蹭、仰头，退出片从主片的最后一个姿态接上并缓慢归位。
- 切换：仅对卡皮巴拉关闭 PNG / 视频层的透明淡入淡出；新视频首帧可绘制时直接切换，视频间加载时保留上一张画面，避免两套脚轮廓短暂叠加。

24 段修复视频共 1,314 帧，逐帧解码检查。以可见区域向内收缩 3 像素后的区域为准，初版最多有 925 个半透明内部像素，修复后每帧均为 0；抚摸和退出片下部脚区像素在渲染前逐帧相同。检验还覆盖视频 alpha 与渲染输入误差不超过 1/255、内部颜色编码平均误差小于 2/255、循环接缝、四脚支撑/摆动轨迹、无空帧与无裁边。检查数量不能代替视觉检查，六年龄的完整分镜、脚部放大图与 GIF 同时保留。

修复备份、渲染过程、生产报告、逐帧检查结果及后台浏览器核验均位于 `output/capybara-motion-repair-20261114/`。每个年龄包的 `source/motion-repair-v2.json` 与 `walk-foot-trajectories-v2.json` 记录新的来源与轨迹。成长规则和真实家庭数据不在此次修改范围内。

后台 Chromium 在真实 PetEngine 中验证六年龄 × 四动作共 24 组，均加载 v2 媒体并使用视频渲染；读取 WebGL 输出确认内部不透明、视频层和静态层没有透明叠放，抚摸主片会进入退出片。1024×768 和 390×844 分别验证实际舞台位移速度与脚部支撑速度一致；另验证没有 gait 元数据的柯基仍沿用原移动时长及淡入淡出。运行无页面错误，类型检查和生产构建通过，7788 静态预览服务已返回 v2 清单与本轮构建的页面。对应证据为 `runtime-check.json`、`published-checks.json`、`delivery-checks.json` 及房间截图。

## 验证与限制

已通过类型检查、生产构建、完整隔离业务回归、18品种首次领养/切换检查，以及12组年龄边界和资源覆盖检查。测试数据库独立，不改真实家庭记录。

122段视频全部用libvpx解码检查6603帧，校验透明通道、空帧、画布边界、帧数和文件散列。真实WebGL引擎验证107组宠物/年龄/动作组合，另检查睡眠中换年龄、视频失败保留同龄PNG、WebGL丢失回退。

页面在1440×900、1024×768、768×1024、390×844进行后台核验：六年龄预览、动作、成长相册、保存刷新、原数据保留、无横向溢出；年龄按钮触控高度不低于44px。未进行iPad Safari真机测试，透明视频不支持时仍会回退同龄PNG。生成图集与神经补帧仍有小幅造型变化，不能称为严格绑定的骨骼动画。

证据集中在`output/pet-growth-20261114/`：`asset-audit.json`、`business-tests.txt`、`browser-engine-check.txt`、`browser-ui-check.txt`、各年龄`review.jpg/render-review.jpg`、走路修前/修后素材、成长对照图及页面截图。
