# 积分明细与快捷惩罚

## 使用方式

- 学生端点击顶部星贝余额打开「积分明细」，可查看当前余额、累计得分和累计扣除，按全部、得分、扣分与支出筛选，并加载更早的历史记录。没有宠物、宠物旅行期间也可以查看。
- 家长端进入「奖励与惩罚」，在快捷惩罚清单中新增项目，填写名称、扣分整数及可选说明。支持编辑、停用、重新启用和删除。
- 点击项目的「扣除 N 星贝」立即扣分，学生和家长的积分明细均可查询。按配置完整扣除，余额不足时可以为负数，页面已明确说明。
- 修改或删除项目不会改变既有扣分记录。每次扣分保存当时的名称、说明、金额和北京时间；零分学习记录显示「积分未变」。兑换奖励和材料等已有支出同时纳入明细。

## 实现与权限

新增 `server/points.mjs`，复用 `point_ledger`，只增加 `penalty_item` 表及查询索引。更新旧数据库不会重置家庭、宠物或学习数据。历史记录使用时间和 ID 共同分页，避免同一毫秒入账时遗漏记录。

`GET /api/v2/ledger` 对当前孩子的学生与家长开放。`/api/v2/penalties` 的查询、保存、删除和执行全部要求家长解锁；家庭到期后仍可查询明细，禁止扣分及配置变更。沿用当前家庭、孩子归属和审计规则。

执行扣分的金额取服务端配置。`POST /api/v2/penalties/:id/apply` 要求请求标识，账本去重键阻止相同请求重试或并发重复扣分；前端请求期间禁用按钮，连接失败时同项目重试沿用标识。
