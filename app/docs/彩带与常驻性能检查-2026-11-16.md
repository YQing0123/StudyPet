# 彩带、常驻性能与场景价格检查

本轮使用独立临时家庭数据库、生产前端构建和后台 Chromium 测试，不使用真实家庭数据。运行记录位于本地 `output/pet-performance-20261116/`。已按固定提交发布流程部署 NAS，版本 2026.11.16-release1，详见对应发布记录。

## 彩带

原动画最后一帧仍有 0.9 不透明度，且组件未移除，因此落地后一直留在场景。现在最后一帧淡出，统一 2200ms 后卸载；26 个粒子位置仅在本次庆祝创建时生成，普通页面刷新不重新随机。旧版和新版共用组件。减少动态效果时隐藏彩带。

真实生产页面通过隔离数据响应触发审批庆祝，确认 26 个粒子出现、约 2.2 秒内清除且不重新出现。睡眠时间切换、宠物换页和组件销毁均清理自己的计时器。

## 常驻性能修复

- 冷却仅在剩余值大于零时倒计时，使用单调时钟校正；后台暂停，回来补齐实际经过时间。3 秒冷却的真实页面测试通过。
- 睡眠改为定时到最近的入睡/醒来边界，删除每秒全页刷新；隐藏暂停，恢复时读取服务端状态并校时。浏览器验证夜间、起床、午休、后台恢复及下一晚，静止期间无每秒重渲染。
- 宠物后台暂停视频、绘制与自动闲置动作，CSS 动画暂停；GIF 后台不再逐帧唤醒。
- 被替换/取消的计时器同步从内部集合移除；销毁释放 WebGL context。
- 通用 GIF/贴图缓存回收不活跃项，最多保留 24 个缓存项（使用中的项保留）。监听器随卸载清理。
- 会话后台不请求；旅行后台不更新时钟和背景。GIF 资源增加正确的 MIME 类型。

## 测量结果

使用 CDP Performance 的主线程 TaskDuration / 测量秒数计算单核等效 CPU；ScriptDuration 对应 JS 时间。数值不是整台机器或浏览器所有进程 CPU。前后使用同一隔离家庭、橘猫、20 清洁度（2 蝇 1 虫）、1440×1000 视口和生产静态构建。

| 同条件 55 秒窗口 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 可见页主线程 CPU | 2.412% | 2.070% |
| 可见页 JS CPU | 0.518% | 0.294% |
| 隐藏页主线程 CPU | 1.407% | 0.048% |
| 隐藏页 JS CPU | 0.276% | 0.003% |
| 隐藏页 timeout 回调次数 | 223 | 0 |
| 隐藏页 interval 回调次数 | 63 | 8 |

隐藏测试通过注入 document visibility 状态并分发事件验证应用响应，未模拟操作系统的全部后台调度，不能等同真实系统后台耗电测量。

另进行预热后的连续两个 45 秒窗口：主线程 CPU 1.054% / 1.132%，JS CPU 0.123% / 0.130%；强制 GC 后堆内存分别变化 -12,680 / -39,488 字节，DOM 与事件监听器增量均为 0。初次加载时的素材解码和缓存增长不作为内存泄漏。

连续创建/销毁 40 次宠物舞台，每次替换 30 次气泡计时器：每批结束活动 timeout 为 0，DOM 数量固定；GIF 隐藏后仅测试自身等待计时器触发。测试共数分钟，不构成连续多日无泄漏保证。前台保留必要的宠物视频和卡通动效，机器、浏览器、场景与素材会影响绝对耗电。

## 场景家具默认价格

阳光花房 120、海风小屋 160、林间木屋 200；初始书房免费。沙发和餐桌椅套组均 180，电视与电视柜套组 200。其他家具原本小于 200 的价格保留，范围 45～200。前后端共用目录，家长手动覆盖价不被迁移覆盖，已兑换的所有权不变。

默认三个学习计划合计每日 37 星贝，付费场景约对应 4～6 天任务积累（不含其他花费或奖励）。
