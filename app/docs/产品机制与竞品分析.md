# 伴学小岛 · 学生/家长机制与竞品分析

本文回答三个问题：现在的机制够不够、还缺什么、市面上哪些产品验证过类似做法。竞品部分按公开产品形态归纳，具体功能以各产品当前版本为准。

## 一、这件事的本质

不是「用积分买宠物」，而是把**孩子自己愿意做的学习行为**，变成**看得见的进度、可兑现的承诺、和一段有回应的关系**。

三个心理支点（自我决定理论）：

| 支点 | 在孩子身上的表现 | 产品里对应什么 |
|---|---|---|
| 自主 | “是我自己安排的” | 自己选先做哪项、自己选完成时间、自己选心愿 |
| 胜任 | “我能做到” | 小步任务、提前完成奖励、可见进度、宠物变强 |
| 联结 | “有人看见我” | 家长审核留言、奖励、宠物回应、家庭仪式 |

积分只是媒介，真正起作用的是：**可预期的规则 + 被看见的努力 + 不羞辱的失败**。

## 二、学生端还应该有的机制

| 机制 | 作用 | 建议形态 |
|---|---|---|
| 最小启动 | 降低开始难度 | 每项任务可拆一个「先做 5 分钟」按钮，做了就算启动，不立即给分 |
| 自选顺序 | 提升自主感 | 任务卡片可拖动排序；不按家长顺序强制 |
| 时间窗可视化 | 让孩子自己安排 | 今天的「时间轴」上标出每项建议时段，而不是只写 16:00–18:00 |
| 提交证据 | 让审核有依据 | 拍照、留言、语音（后续）；不要求每项都拍 |
| 退回可重来 | 失败不污名 | 退回只写“下一步怎么做”，不写“你怎么又…” |
| 连续打卡保护 | 防断签崩溃 | 每月 1 次「补签卡」，用星贝换或家长赠 |
| 每周回看 | 形成反思 | 周日一页「这周我做到了什么」，宠物给一句总结 |
| 心愿进度 | 长线目标 | 心愿卡片显示“还差 20 星贝”，可拆成小目标 |
| 宠物日记 | 情感联结 | 记录“今天被摸了 3 次/吃到小鱼干/陪你写完数学” |
| 选择权 | 防厌倦 | 同一任务允许多种完成方式（读、讲、写、录音） |
| 兄弟姐妹/同伴 | 社交激励 | 默认不做排行榜；只做「家庭共同目标」，避免比较 |
| 离线任务 | 覆盖真实生活 | 运动、家务、练琴也可作为计划，不局限书面作业 |

## 三、家长端还应该有的机制

| 机制 | 作用 | 建议形态 |
|---|---|---|
| 计划模板 | 降低每天编排成本 | 「工作日模板」「周末模板」「期末周模板」，一键套用 |
| 复制上周 | 减少重复劳动 | 一键把上周计划复制到本周，保留规则 |
| 临时任务 | 应对当天变化 | 单日加一项，不影响固定计划 |
| 暂停计划 | 生病/旅行 | 暂停到某天，不产生“未完成” |
| 批量审核 | 降低负担 | 多选通过；退回必须写一句原因 |
| 常用退回语 | 降低沟通成本 | “字再工整一点”“生词还没标”“照片看不清” |
| 快速奖励 | 强化正反馈 | 审核页一键 +5/+10/+20，附一句原因 |
| 周报 | 看见趋势 | 完成率、提前率、待审、连续天数、下周建议 |
| 公平设置 | 多孩家庭 | 每个孩子独立积分与心愿，不做横向对比 |
| 通知摘要 | 不打扰 | 默认只推「待审核」和「退回」，不推每条完成 |
| 规则边界 | 防家长代做 | 审核只判断“是否完成”，不替孩子改内容 |

## 四、竞品与相似机制

| 产品 | 核心机制 | 可借鉴 | 缺口/注意 |
|---|---|---|---|
| 星目标（微信小程序，公开形态） | 家长设目标/任务，孩子完成得星，星星换奖励 | 极简的“目标—星星—奖励”心智；家长自定义奖励 | 规则粒度通常较粗；缺少学习过程证据与宠物陪伴 |
| 小日常 / 习惯打卡类 | 习惯清单、连续天数、提醒 | 低摩擦打卡、连续激励 | 容易变成“为打卡而打卡”，奖励与真实成长脱节 |
| 番茄ToDo | 专注计时、白噪音、任务清单 | 时间窗与专注感 | 偏工具，缺家庭互动与奖励兑现 |
| OurHome（家庭家务/积分） | 家务分配、积分、奖励商店、家长审批 | 家庭成员分工、审批、兑换闭环 | 偏家务，不是学习计划；界面偏成人 |
| Greenlight（美国家庭理财） | 家务/任务与零花钱、家长审批、消费控制 | “任务—钱—自主支配”的财商闭环 | 金钱激励强，低龄孩子容易只看钱 |
| BusyKid | 家务、零花钱、储蓄/投资/捐赠 | 奖励分流（花/存/捐） | 同上，偏金钱 |
| ClassDojo | 课堂积分、家长端消息、行为反馈 | 家长可见的即时反馈、正向行为强化 | 学校场景，积分偏行为标签，缺家庭计划 |
| Habitica | 游戏化习惯、任务、奖励、组队 | 角色成长、装备、公会 | 成人向，规则复杂，孩子上手成本高 |
| Khan Academy Kids / 学习类 | 学习路径、徽章、进度 | 掌握感与进度可视化 | 内容闭环强，家庭奖励弱 |

**结论**：市面上「任务—积分—奖励」很成熟，「家长审核 + 学习证据 + 宠物陪伴」的组合不常见。我们的差异点应放在：

1. **家长只做规则与审核，不替孩子学习**；
2. **积分与宠物成长是两套节奏**：积分快、宠物慢，避免“刷分”；
3. **失败可重来，不扣光、不羞辱**；
4. **规则透明**：孩子能看到每项任务的积分、时间窗和审核要求。

## 五、积分与奖励的设计原则

| 原则 | 做法 | 反例 |
|---|---|---|
| 奖励努力与坚持，不只为结果 | 完成、提前、连续、主动帮助都给分 | 只按考试分数给大额奖励 |
| 不预支 | 审核通过才到账 | 先给分再审核，退回时已花掉 |
| 不通胀 | 任务分与材料价联动；心愿定价有上限 | 动辄 500 分，材料 10 分 |
| 不惩罚生存 | 宠物不会死、不会永久离开 | 饿死宠物、清零积分 |
| 延迟满足 | 心愿需要攒几天 | 所有奖励当天兑现 |
| 自主选择 | 孩子选先做哪项、换什么 | 家长全权指定，孩子只执行 |
| 家庭仪式 | 周日一起看周报、兑现心愿 | 只有冷冰冰的分数 |

## 六、通知与审批的技术选型

| 方案 | 接入成本 | 及时性 | 适合 | 限制 |
|---|---|---|---|---|
| 企业微信群机器人 Webhook | 最低，群设置里加机器人复制 URL | 实时 | 家庭群/小团队 | 需要有企业微信群；消息是群消息 |
| 钉钉群机器人 Webhook | 最低，同上 | 实时 | 用钉钉的家庭 | 需要有钉钉群 |
| PushPlus | 低，关注公众号拿 token | 实时 | 个人微信 | 第三方服务，有频率/额度限制 |
| Server酱 | 低，同上 | 实时 | 个人微信 | 第三方服务，免费额度有限 |
| 微信公众号模板消息 | 中高，认证服务号、openid、模板 | 实时 | 有公众号的团队 | 认证、用户授权、48 小时窗口 |
| 小程序订阅消息 | 中高，用户每次授权 | 实时 | 小程序产品 | 一次授权一次推送，需前端配合 |
| 本机 Agent 推送（如当前 DSH 的微信通道） | 最低（已有通道） | 实时 | 单机自用/演示 | 依赖本机 Agent 在线，不适合多家庭 |

**建议**：MVP 先接**企业微信/钉钉群机器人**，一个 HTTP POST 即可；个人微信优先 **PushPlus**。消息里带一个签名链接，家长点开就是待审核页，不在聊天里做复杂交互。公众号模板消息/小程序订阅消息放到有正式主体后再做。

## 七、风险与边界

- **过度理由效应**：把原本喜欢的事全部标价，会削弱内在动机。阅读、运动等可给“成长值/徽章”，少给可兑换积分。
- **审核变成监工**：家长每天审 10 项会累。默认只审“需要证据”的任务，其余自动通过；批量通过。
- **刷分**：同一任务一天只能发一次；审核才入账；照片与时间戳留痕；撤销要校验余额。
- **兄弟姐妹比较**：不做公开排行榜；用家庭共同目标。
- **奖励通胀**：心愿定价与任务分挂钩，定期复盘；不轻易加价。
- **隐私**：照片只存本机；通知只发任务标题，不发孩子正脸/成绩细节。
- **家长工作量**：计划模板、复制上周、批量审核、常用退回语是留存关键。

## 八、建议路线

| 阶段 | 内容 | 出口 |
|---|---|---|
| P0（已具备） | 每日任务、积分、材料、宠物、审核、日历、心愿 | 一个家庭跑通一天 |
| P1 | 周模板/复制上周、批量审核、退回常用语、周报 | 家长每天操作 < 3 分钟 |
| P2 | 通知（企业微信/钉钉/PushPlus）、照片证据、连续保护 | 家长手机收到待审提醒 |
| P3 | 周回看、宠物日记、家庭共同目标、多孩公平 | 孩子愿意主动打开 |
| P4 | 学习内容接入（教材/题目）、数据导出、多端 | 回到完整学习闭环 |

## 九、可观测指标

- 家长侧：每日审核耗时、待审积压、计划模板使用率、退回率。
- 学生侧：主动打开率、任务启动率、提前完成率、连续天数、心愿兑换周期。
- 关系侧：家长留言/奖励次数、孩子主动互动次数、周回看完成率。
- 反指标：只为积分刷简单任务、退回后不再提交、宠物长期低状态、家长连续一周不审核。
