# 全品种开放与卡通柯基试制

## 产品结果

原有 16 个品种全部开放，加上新增「卡通柯基」共 17 个：猫 4、狗 5、鸟 4、龟 4。首次领养与舞台「⋯ → 选择宠物」共用品种清单，支持物种筛选。选择器先播放预览，点击保存才改当前宠物；只改 breed/species，保留宠物 ID、名字、领养日期、成长、星贝、计划、材料、装扮与冷却。

用户任务是「先看看每只宠物的样子和动作，再选喜欢的继续养」。采用现有菜单和 Sheet 承载：打开菜单 → 选择宠物 → 点候选 → 保存，四次点击；没有新增页面、账户或确认步骤。预览与动作不写业务数据，失败时保留候选和弹层，可直接重试。用户可选回原品种。

沿用暖纸色、森林绿、现有 Chip、Sheet 和按钮。移动端候选选中后回到预览；保存区固定在底部，预览走路限制在小场景内部。首次领养的手机卡片缩减重复说明，取名与领养按钮随列表滚动保持可达。动效沿用弹层进出、宠物动作和提示，没有另立视觉体系。

## 角色锁定与生成

按用户选定的 **gpt-image-2.6-sunburst / high**，使用已授权的 Image API CLI fallback。先从原卡通柯基提取参考，再生成一张 2048 方形母版；六段动作均输入同一张母版，提示词固定：橙白毛、白额斑、深棕眼、黑鼻、粉色内耳、短腿长胖身、短尾、三分之四朝右、柔和水彩、固定镜头与光线。

母版及原始参考在 `assets/pets/dog_corgi_toon/source/`，完整提示词在其 `prompts/` 子目录。没有每个动作重新发明角色。实际动作仍有小幅轮廓、眼神和姿态差异，不能保证逐像素身份一致；这是一套供用户评审的试制素材。

六个原生 GIF 均实际返回 **9 帧、每帧 200ms、共 1.8 秒、循环播放**，边长约 413–439px。母版是 2K，动画原件不具备 2K 分辨率。坐姿首次请求返回非 GIF，已判失败并重试，成功的原件命名为 `sit-native-retry.gif`。所有原件保留原始字节，散列、尺寸和时长记录在 `source/production.json`。

## 生产处理与真实动作映射

脚本 `scripts/build-corgi-toon.py` 完全离线：洋红背景软抠像 → 边缘去洋红 → 连通域清理额外动作线 → 按眼间距统一尺度 → 平移对齐地面 → 512 方形发布。保留白毛、黑眼、碗和绿球。

曾试用光流补帧，但爪子和球出现重影，因此最终删除补帧，保留原生清晰关键帧。WebM 用 24 fps 容器编码，重复持有关键帧；这不代表模型输出了 24 个不同画面/秒。成品是 VP9 alpha，经既有 WebGL 播放器显示，走路位移仍由容器完成。

| 产品动作 | 视频键 | 来源与处理 |
|---|---|---|
| 坐姿/打招呼 | greet | 原生 sit 的呼吸、眨眼、耳尾动作 |
| 走路 | walk | 原生 walk，循环步态 |
| 进食 | eat → eatrev | 原生 eat 前六关键帧吃饭，后四关键帧抬头退出 |
| 抚摸 | petted → petted-out | 原生 pet 的闭眼、歪头与摇尾；后四关键帧恢复 |
| 陪玩 | play | 原生 play，抬爪拨绿球 |
| 睡下 | sleep | 原生 sleep，坐下到趴下闭眼 |
| 醒来 | wake | 同一 sleep 序列倒放 |
| 抱抱 | hug | 复用 petted；没有独立抱抱原生动画 |

六个静态键中 sit/walk/sleep 来自对应片；jump/roll/stretch 从 play/sleep 选取邻近姿态，用于兼容现有静态回退，不能称为独立跳跃、翻滚、伸懒腰动画。没有生成 walk-start、walk-stop、feedcatch，关闭了该包的走路起止片开关。

## 增加下一只宠物

1. 先定一张角色母版与一致性约束，再以同一母版制作动作；保留原件和提示词。独立检查脸、花色、体型、朝向、道具与首尾，不把「同一提示词」当作一致性验收。
2. 建立 `assets/pets/<breed>/pet.json`，声明 avatar、frames、videos、bottom、mode 和 walkTransitions。发布版本为透明 PNG / VP9 alpha，原件放 source，不写入逆向归档。
3. 在 `web/src/mvp/petBreeds.ts` 登记产品名称，在 `server/daily.mjs` 登记物种和成长速度，在 `breedConfig.ts` 登记尺度、朝向与声音。自有包由复制脚本自动写入 manifest。
4. 按顺序运行制作脚本、素材复制、类型检查、隔离回归与构建；不要边生成边复制。新动作要在浅底、深底与实际房间里检查，再测试切动作、睡醒、走动边界、失败回退和保存后刷新。

v1阶段的离线复现命令（仅作历史记录；当前v3请按《宠物素材制作与接入》文末命令）：

```sh
python3 scripts/build-corgi-toon.py
npm run assets:copy
npm run typecheck
npm test
npm run build
```

这些命令只使用已保存原件，不会再次调用付费生成。后续若需要更流畅且严格保持同一结构，建议基于这张母版分层绘制和二维骨骼/人工逐帧，再导出透明 WebM；本次原生九帧不可通过简单补帧变成同等级的精细动画。
