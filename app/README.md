## 学生端能做什么

- **学习挑战**：选择古诗词或数学计算、三档难度、普通或翻倍玩法；默认每天共用 3 次、每轮 10 题、最多 10 分钟，家长可调整，累计奖励不设上限；查看解析、结果和保留掌握历史的错题本
- **今日计划**：按科目、时间窗、积分、图标展示；点卡片看完整规则（按时 +N、提前 +N、超时 −N、是否审核/拍照）
- **提交任务**：写一句给家长的话、拍照上传；提交后显示「等家长审核」
- **审核状态**：待审核 / 已通过 +N / 被退回（含原因，可重交）；家长通过后星贝才到账
- **宠物**：PNG 帧 + WebM 透明视频 + WebGL 抠像；走动、摸头、吃饭、陪玩、抱抱、睡觉/叫醒
- **手动成长**：主进度条显示下一年龄阶段、还差多少成长/时间和每日额度；支持同龄星章、跨龄变身、跳过、减少动态效果及档案重播
- **四项需求**：饱食、精力、心情、清洁；随时间衰减，照顾会恢复；饿了/脏了/累了会拖累心情
- **材料铺 + 背包**：食物、玩具、清洁、装扮；成长每 50 掉一件材料
- **心愿奖励**：家长上架的 Switch 时间、奶茶、电影等，用星贝兑换
- **小憩**：恢复精力（有冷却）；状态说明弹层解释每项数值受什么影响
- **定时睡眠**：按家长安排夜间休息与午休，显示起床时间；睡梦中轻点会翻身说梦话，持续打扰先警告后少量扣心情，醒来再照顾
- **场景布局**：照顾按钮竖排靠左，四项状态与宠物信息位于场景顶部；底板40%不透明。学生端顶部合并孩子切换、星贝余额、姓名（家长端）与退出，去掉独立家庭信息栏；顶部显示家庭名称，底部依次为计划、旅行、挑战、小岛、材料、心愿、背包，小岛居中并默认选中。桌面和横屏平板填满可视区域，仅任务列表内部滚动并露出半项。窄屏改为上下浏览
- **今日小纸条**：真实任务进度与当天家长留言轮播，可暂停、手动切换、让宠物在头顶气泡转述。右上角可让宠物用气泡说一遍，已移除语音朗读

## 家长端能做什么

- **学习挑战**：设定每日免费 0–20 次、每轮 5–20 题、最长 1–60 分钟，以及年级/学期、数学已学知识、普通诗词篇目、预习和翻倍开关；普通奖励按 80%/90%/100% 正确率分档，默认 10 题对应 8/9/10 题得 10/13/16 分，难度逐级翻倍；翻倍玩法最多领取 512 分
- **待审核**：看照片、留言、完成时段和预计积分；通过或写原因退回
- **周计划**：每天重复或按星期几；科目、图标、预计用时、建议时段、按时/提前/超时积分、是否审核、是否拍照
- **日历**：按月看每天任务数、通过数、待审/退回/提前标记；周汇总、月汇总
- **奖励**：
  - 直接赠送星贝（附原因）
  - 上架自定义心愿（名称、图标、星贝价、库存、说明）
  - 兑现/退回学生兑换
  - 修改内置宠物材料价格
- **家庭与账号**：多个家长同权管理、审核多个孩子；开通/重设学生账号、一次性家长邀请码、加入其他家庭、修改自己的密码。学生仅能访问自己的记录
- **小纸条**：给当前孩子发送80字以内的当天留言；每位家长每天一张，可以更新，家庭内家长同权撤回；发送失败保留输入，学生端12秒内同步
- **设置**：宠物作息、通知与材料价格；企业微信/钉钉群机器人或 PushPlus 推送，支持发测试消息；重新开始当前孩子需家长确认
- **原则**：家长只定规则与审核，不替孩子学习；改计划不会追回已发奖励

## 设计方向

一句话：**一间会呼吸的水彩书房**。学生端把宠物当情绪重心，暖纸色、鼠尾草绿、软杏色，低对比、大圆角、52px 以上触控目标；家长端沿用同一套纸感，但减少装饰、突出待办和数字。交互上一条主线：**今天做什么 → 点开看规则 → 提交 → 等审核 → 星贝到账 → 换东西/陪宠物**。

已做的动效：宠物呼吸、走动/摸头/吃饭/睡觉、任务提交后的等待态、通过后的彩带与星贝飘字、底部导航与弹层过渡。

## 主要接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/auth/session` | 当前账号、家庭成员与可访问的孩子 |
| POST | `/api/auth/login` | 登录并建立持久会话 |
| GET | `/api/v2/student` | 学生今日：任务、积分、宠物、背包、心愿、审核状态 |
| GET | `/api/v2/parent` | 家长端：待审、规则、日历、周/月汇总、奖励、设置 |
| POST | `/api/v2/rules` | 新建/编辑周期计划 |
| DELETE | `/api/v2/rules/:id` | 删除计划 |
| POST | `/api/v2/tasks/:id/submit` | 学生提交（note/photo） |
| POST | `/api/v2/tasks/:id/review` | 家长通过/退回 |
| POST | `/api/v2/points/gift` | 家长赠分 |
| POST | `/api/v2/rewards` | 上架/编辑心愿 |
| POST | `/api/v2/rewards/:id/redeem` | 学生兑换 |
| POST | `/api/v2/redemptions/:id/handle` | 家长兑现/退回 |
| POST | `/api/v2/settings` | 通知、材料价格 |
| POST | `/api/v2/notes` | 给当前孩子发送/更新自己的当天小纸条 |
| DELETE | `/api/v2/notes/:id` | 家长撤回当前孩子当天的纸条 |
| POST | `/api/v2/pet/rest` | 小憩恢复精力 |
| POST | `/api/v2/pet/breed` | 更换品种，保留名字、成长、钱包和计划 |

宠物互动仍走 `/api/pet/interact`、`/api/pet/use`、`/api/shop/buy`，与 v2 共用积分账本与宠物状态。业务接口均校验账号、家庭成员及孩子归属；家长操作还需管理权限解锁。完整账号说明见 [家庭账号接入](docs/账号与家庭接入-2026-11-13.md)。

- 照片以 data URL 存 SQLite；正式版应存对象存储并压缩
- 通知只实现 webhook/PushPlus 客户端；公众号模板消息、小程序订阅消息未做
- 19 个品种已开放领养与保留记录的更换；原有素材的身份/风格差异仍待逐套重制
- 原程序透明置顶窗、点击穿透、拖拽、多屏 DPI 无法在网页等价复刻
- 部分源片存在角色、画风和构图差异；本轮修复透明、纸边与局部缺损，并按实际脚底定位，仍需逐套替换源内容，见 `scripts/patches/README.md`

## 公网安全、开通邀请码与家庭有效期（2026-11-16）

家长端“家庭管理”可查看套餐/期限并兑换续期码。全家共用有效期，7 天内提示即将到期；到期后保留登录、历史查看和安全操作，暂停业务写入，续期后立即恢复。已有家庭升级时保留不限期，由管理员决定是否设置期限。成员邀请、家庭开通和家庭续期分别使用不同用途的邀请码，不能混用。

## 2026-11-14 iPad Chrome 动作兼容修复

iPad 上的 Chrome 使用 WebKit，部分版本无法正确解码原 WebM/VP9 的透明通道；旧逻辑会退回单张 PNG，位置移动继续运行，因此表现为“宠物会移动，但没有动作帧”。播放器现在按浏览器能力优先使用普通 H.264 MP4：透明动作将 RGB 与灰度透明蒙版左右打包，WebGL 同帧还原透明；绿/蓝幕动作继续按原方式抠像。视频显式静音、内联播放，解码元素保持参与渲染。兼容源加载失败时重试原 WebM，均失败才降级静态图。
