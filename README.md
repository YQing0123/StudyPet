## 为什么做伴学小岛

读完一本书、完成一页口算、坚持十分钟运动，这些小事需要时间才能看见变化。伴学小岛希望给孩子一个更近、更具体的期待：**今天认真完成的小计划，可以让自己的小伙伴过得更好，让自己的小岛多一点喜欢的东西。**

孩子通过打卡和学习挑战获得「星贝」，为宠物准备食物、洗澡、换装，慢慢添置家具，再等它从旅行中寄回一张明信片。家长负责安排节奏、审核记录、设置奖励，也可以写一张鼓励的小纸条。

陪伴、成长、布置和收集，让日常打卡有了可以持续积累的目标。学习计划由家庭自己决定，阅读、运动、家务和兴趣练习都可以成为计划的一部分。

## 一家人怎么使用

| 使用视角 | 日常可以做什么 |
| --- | --- |
| **学生端** | 看今日计划、提交学习记录、参加挑战、照顾宠物、布置小岛、旅行和收藏、兑换小心愿。 |
| **家长端** | 安排周计划、审核打卡、看日历与统计、管理奖励、写小纸条、配置挑战和作息、查孩子的错题本。 |
| **独立管理端** | 管理家庭与使用期限、签发开通和续期码、分页查询题库、停用或恢复题目。入口为 `/admin`。 |

一个家庭可以有多位家长、多个孩子。孩子可以使用独立学生账号，家长切换孩子查看各自的计划、宠物和学习记录。

日常使用流程：

1. **定一个小目标**：家长按星期安排任务，选择时间段、星贝奖励，以及是否需要拍照或审核。
2. **让努力留下记录**：孩子完成后提交照片或留言；需审核的任务由家长确认，免审核任务自动通过。
3. **收到看得见的回报**：星贝到账，用来照顾宠物、兑换场景家具，也能兑换家长准备的心愿。
4. **积累下一份期待**：宠物逐渐成长，房间逐渐丰富，旅行收藏逐渐增加，再回到明天的小计划。

## 功能与玩法

### 每天都有进度，也有鼓励

- **周计划与今日任务**：按周一至周日安排不同任务，支持科目、预计分钟、完成时段、提前奖励与超时规则。
- **打卡与审核**：照片、留言、通过、退回与重新提交；任务奖励统一记入星贝账本，同一任务不会重复领分。
- **日历与统计**：回看每天的记录，了解本周完成情况和连续打卡情况。
- **小纸条与心愿**：把鼓励留在孩子的小岛上，也把「一起看电影」「挑一本新书」变成家庭约定的奖励。

### 养一位会成长、需要照顾的小伙伴

当前开放领养 **橘猫、卡通柯基、卡皮巴拉、羊驼** 四种伙伴。宠物有饱食、精力、心情和清洁状态，可以喂食、陪玩、摸摸、抱抱和休息。

- **长期成长**：成长结合自然时间与日常陪伴，分为六个年龄阶段、每阶段初阶和进阶；满足条件后手动确认升级。不同品种的动作与年龄外观完整度仍在迭代。
- **清洁与洗澡**：每天一次免费简单淋浴有清洁度门槛和恢复上限；比较脏时需要使用泡泡浴。洗澡、清洁和闪光通过通用图层呈现。
- **真的戴上装扮**：小皇冠戴在头部，蝴蝶结系在颈前，两件可以一起穿戴；兑换后可反复使用。
- **一起规律作息**：家长设置夜间睡眠、起床和午休时间，到点自动睡觉。睡觉时互动会出现翻身与梦话；持续打扰会先提醒，再按规则小幅影响心情。

### 用收集的小物件，布置自己的小岛

目前有 **4 套场景、16 件家具**，包括花房、海风小屋、林间木屋，以及沙发、书架、盆栽、灯具、电视柜和餐桌椅等。

- 场景和家具兑换后永久拥有，在背包里切换和摆放。
- 长按家具进入编辑，也支持键盘回车进入；可拖动、旋转、缩放、调整与宠物的前后层关系。
- 每套背景都配有日间和夜间版本，按北京时间 **19:00 切换夜景，07:00 切回日景**，家具布局保持一致。
- 当前可兑换场景为 **120 / 160 / 200 星贝**，家具为 **45–200 星贝**，逐步收集就能添一点新变化。

### 宠物去看世界，把一路风景带回来

宠物达到少年阶段后解锁旅行。选择目的地和 **1 / 2 / 3 / 5 小时**的行程，就可以暂时告别，等它带着行囊回家。

目前覆盖 **24 个目的地、168 种收藏**，包括城市明信片、地方美食、伴手礼、徽章和稀有纪念物。不同城市有自己的风景与寄语，已获得的收藏可随时回看。返程后先查看收获，再查收入背包和钱包。

### 学习挑战，让练习也有一点期待

支持 **古诗词** 与 **数学计算**，可选择普通、挑战、困难三个难度。家长按孩子的实际学习进度设置范围，并调整每天免费次数、每轮题量和最长时间。

| 玩法 | 奖励规则 | 适合的节奏 |
| --- | --- | --- |
| **普通模式** | 完成整轮后按正确率分档奖励，达到 80% 起发奖，难度提高会增加奖励。 | 认真完成一组练习，回看掌握情况。 |
| **翻倍模式** | 连续答对暂存星贝递增，第 3 题起可结束领取；答错或超时会清空本轮暂存，已有钱包余额不受影响。家长可关闭。 | 在规则内决定继续还是领取。 |

古诗词题库基于 155 首清单；数学当前支持一年级上、下册及二年级上册的已实现范围，后续继续扩充。题目覆盖以当前版本与家长端可选范围为准。

![学习挑战大厅：学科、难度、普通与翻倍模式、每日机会](app/docs/screenshots/student-challenges.png)

### 错题留下来，进步才能看得见

做错的题会进入错题本，后续挑战会在符合当前学习范围的题目中安排复习。答对后标为已掌握，再次做错仍保留掌握历史。

家长端提供累计错题、待巩固、已掌握、掌握后再错统计；支持学科、掌握状态、关键词、再错条件和排序组合查询，以及 **20 / 30 / 50 条分页**。每道题可查看答案、解析和历史答题次数。

## 快速安装

推荐使用 Docker。运行所需的前端、服务端和 SQLite 都包含在本地构建的镜像中；日常打卡和养宠不需要配置模型 API Key。仓库没有预设可用密码，也不包含真实家庭数据。

### 方式一：Docker 部署

准备 Git 和支持 Linux 容器的 Docker（含 NAS Docker / Container Manager）。在仓库根目录执行：

```bash
git clone https://github.com/YQing0123/StudyPet.git
cd StudyPet

docker build -t studypet:local ./app

docker run -d \
  --name studypet \
  --restart unless-stopped \
  -p 127.0.0.1:7788:7717 \
  -e BANXUE_ALLOW_HTTP=1 \
  -v studypet-data:/data \
  studypet:local
```

浏览器打开 **<http://127.0.0.1:7788/>**。上述配置用于本机 HTTP 体验，数据保存在命名卷 `studypet-data`，容器重启后保留。

首次运行后创建独立管理员：

```bash
docker exec -it studypet node scripts/admin-account.mjs island-admin
```

按提示设置至少 12 位的管理员密码，然后访问 **<http://127.0.0.1:7788/admin>**。密码通过交互输入。同一命令也可重设已有管理员密码。

**NAS 与域名访问**

- NAS 上可用 `app/Dockerfile` 构建镜像，将容器内端口 `7717` 映射到自己的端口，将持久数据挂载到 `/data`。
- 仅在可信的隔离局域网进行 HTTP 试用时，保留 `BANXUE_ALLOW_HTTP=1`，将端口映射改为 `7788:7717`，从局域网访问 `http://NAS_IP:7788`。
- 公网访问应配置 HTTPS 反向代理，设置 `BANXUE_PUBLIC_ORIGIN=https://pet.example.com`，移除 `BANXUE_ALLOW_HTTP=1` 或设为 `0`。前端和 `/api` 统一转发到同一个服务，保留原始请求来源信息。
- `BANXUE_PUBLIC_ORIGIN` 必须与浏览器访问的 HTTPS 来源完全一致，可含端口，不能带子路径。使用单独域名部署。
- 使用宿主机目录挂载时，运行用户 UID/GID 为 `1000:1000`，数据目录需要具有对应写入权限。

| 配置项 | 用途 |
| --- | --- |
| `BANXUE_DATA_DIR` | 数据目录；镜像中默认 `/data`，包含数据库和任务媒体。 |
| `BANXUE_PUBLIC_ORIGIN` | 公网 HTTPS 来源，例如 `https://pet.example.com`。 |
| `BANXUE_ALLOW_HTTP` | 无公网来源时的显式 HTTP 试用开关；上述本机体验示例设为 `1`。 |
| `PORT` / `HOST` | 镜像内默认监听 `0.0.0.0:7717`。 |
| `TZ` | 镜像默认 `Asia/Shanghai`；宠物作息与日夜切换按北京时间。 |

### 方式二：源码运行

需要 **Node.js 24** 和 **pnpm 10.11.0**。后端使用 Node 内置 `node:sqlite`，无需另装数据库服务。

```bash
git clone https://github.com/YQing0123/StudyPet.git
cd StudyPet/app

npm install --global pnpm@10.11.0
pnpm install --frozen-lockfile

# 创建管理员，按提示输入密码
pnpm admin:account island-admin

# 同时启动 API 和开发页面
pnpm dev
```

开发页面：**<http://127.0.0.1:5199/>**；管理员入口：**<http://127.0.0.1:5199/admin>**；API 默认端口：`7717`。源码默认数据目录为 `app/data/`，可通过 `BANXUE_DATA_DIR` 自定义；创建管理员和启动服务应使用同一个数据目录。

如需构建后同源运行，在 `app/` 执行：

```bash
pnpm build
pnpm preview
```

构建后的入口为 **<http://127.0.0.1:7717/>**。公网使用仍需 HTTPS 代理与正确的 `BANXUE_PUBLIC_ORIGIN`。

## 第一次进入小岛

1. 打开 `/admin`，使用刚刚在本机创建的管理员账号登录。
2. 进入「邀请码」，签发一个用于**新家庭开通**的开通码，保存生成时显示的完整码。
3. 回到家庭入口，选择「创建家庭」，填写开通码、家长账号、家庭名称和孩子信息。
4. 进入学生端，领养第一位学习伙伴；到家长端调整示例周计划和心愿奖励。
5. 按需在「家庭管理」中邀请另一位家长，或为孩子创建独立学生账号。
6. 设置学习挑战范围、每日次数和宠物作息，开始第一天的打卡。

**开通码和家庭期限由自己的部署管理员管理，不需要向项目作者购买，也不依赖作者的在线服务。** 自用家庭创建后，管理员可以在「家庭管理 → 管理期限」中改为「不限期」。家庭成员邀请码用于加入已有家庭，与新家庭开通码不同。

## 更新、备份与常见问题

### 如何跟进新版本

项目目前仍在快速迭代，请关注 [GitHub 版本标签](https://github.com/YQing0123/StudyPet/tags)。`main` 为当前开发进度，需要固定版本时，在构建前使用 `git checkout <tag>` 切换到对应标签。

Docker 更新流程：备份数据 → 获取目标版本 → 重新构建镜像 → 重建容器并挂回原数据卷。

```bash
git pull --ff-only
docker build -t studypet:local ./app

# 先完成下方备份，再重建容器
docker stop studypet
docker rm studypet

# 重新执行安装时的 docker run，沿用 studypet-data:/data
```

使用固定标签的检出状态时，应先切换到目标新标签，不直接执行 `git pull`。重新启动时保留自己的端口、域名等配置。

### 数据怎么备份

Docker 推荐在停止容器后备份**整个数据目录**，将 SQLite 数据库和任务媒体一起保存。例如：

```bash
docker stop studypet
mkdir -p backups
docker cp studypet:/data ./backups/studypet-data
docker start studypet
```

每次备份请使用新的目标目录。源码部署则停止服务后复制 `app/data/`（或自定义数据目录）。家长端的「宠物备份」用于恢复宠物状态，完整站点迁移仍需要整个数据目录。

### 登录提示「请求来源不受信任」

通常是实际访问地址与 `BANXUE_PUBLIC_ORIGIN` 不一致，或反向代理改写了请求来源。检查浏览器访问的协议、域名和端口，以及代理的 `Origin` / `Referer` 转发；公网使用匹配的 HTTPS 来源，本机 HTTP 体验使用上面的明确配置。

### 是否需要付费服务或生图接口

日常运行使用仓库中已有的宠物、场景和旅行素材，不需要连接生图服务。素材生产脚本供继续开发时使用，生成新素材需要自行配置对应工具。
