# 伴学小岛技术详细设计

## 1. 系统结构与技术决策

### 1.1 服务结构

系统采用模块化单体。一个Web应用提供儿童端、家长端和电视布局；一个API服务处理身份、内容、计划、学习、奖励和宠物；一个轻量任务进程执行可恢复的后台任务；PostgreSQL保存业务真值；媒体保存在持久化目录。文档解析、语音模型和素材构建为可选独立进程，不参与儿童作答的同步关键路径。

开发工程采用pnpm workspace。领域规则写成无网络、无界面的TypeScript纯函数；数据库事务、文件服务、模型调用和HTTP路由分别作为适配层。API与worker共享领域包，Web只共享公开契约、展示枚举和可复用校验代码，不导入私有答案、发奖算法或数据库凭据。

| 技术层 | 设计选择 | 使用方式 |
|---|---|---|
| 运行时 | Node.js 24 LTS、TypeScript | 应用与轻量worker同版本，镜像锁digest |
| Web | React 19、Vite、React Router | 一套业务路由，child/parent/tv三种布局 |
| 数据读取 | TanStack Query | 缓存服务端查询、失效刷新；不把缓存当余额真值 |
| 表单 | React Hook Form＋应用生成的校验器 | 复杂家长表单、错误定位；儿童端保持一题一动作 |
| 状态机 | XState稳定5.x | 会话与行为编排，快照带machine_version；不负责数据库幂等 |
| 图形 | PixiJS 8 WebGL | 用ref封装场景生命周期，逐帧不触发React重渲染；@pixi/react非必需 |
| 轻量回退 | DOM/SVG＋CSS/WAAPI | WebGL失败时仍可学习、喂食和显示静态宠物 |
| 后端 | Fastify 5＋TypeBox/JSON Schema＋Ajv 8 | 统一参数校验、公开/私有DTO、OpenAPI导出 |
| 数据访问 | PostgreSQL 16＋node-postgres＋Kysely | 显式事务、行锁与SQL约束；DDL迁移独立管理 |
| 文件 | 本机持久化目录＋内容摘要键 | API受控读取；未来可替换S3适配器 |
| 任务 | PostgreSQL任务表、SKIP LOCKED、租约 | 单家庭无需Redis/Kafka；并发与重试可配置 |
| 导入增强 | 独立Python/Docling worker | CLI/队列处理PDF/OCR，核心应用不携带大模型 |
| 部署 | Docker Compose、NAS反向代理 | amd64/arm64镜像，可信HTTPS，同源API与媒体 |
| 验证 | Vitest、Fastify inject、PostgreSQL集成测试、Playwright | 测试与业务风险对应，真实iPad/TV另行验收 |

依赖的精确patch版本在初始化工程时写入锁文件并通过兼容检查；框架主版本是设计约束，不复制预览版文档的API。首版不加入向量数据库、微服务、开放代码插件、完整LMS、实时三维或浏览器常驻语音大模型。

### 1.2 模块职责与依赖

| 模块 | 拥有的数据和命令 | 允许依赖 | 禁止行为 |
|---|---|---|---|
| identity | 家庭、账号、孩子、设备、会话 | audit、配置 | 前端提交family_id就授予访问 |
| curriculum | 原文、版本、节点、切片、目标、媒体映射 | media、identity | 修改已发布原文payload |
| authoring | 导入、AI候选题、质量报告、发布/撤回 | curriculum、jobs、model-gateway | 模型输出直接给孩子作为正式题 |
| planning | 周计划、修订、学习日、稳定任务与scope | curriculum、question-bank、identity | 改计划重置奖励资格 |
| learning | 接触声明、训练、挑战、作答、复核、证据 | planning、question-bank、media | 计时自动产生掌握；相信客户端正确率 |
| rewards | 资格、发放、库存、账本 | learning的确认结果、identity | 动画回调发奖；内容包自定奖励数 |
| pet-world | 宠物状态、照顾、成长、医院、场景、回忆 | rewards、learning、asset-registry | 自行判定题目或绕过账本扣库存 |
| asset-factory | 参数化角色、生成图集、动作与场景包 | 隔离构建器、质量工具 | 在儿童端执行生成的TS/Python |
| companion | TV配对、输入命令、录音伴侣 | identity、learning、sync | 手机和电视各自成为会话真值 |
| operations | 备份、健康、审计、后台任务与同步 | 所有模块的受控只读/管理接口 | 公开数据库管理端口或返回秘密 |

模块之间通过应用服务接口和版本化领域事件通信。核心学习完成、奖励、库存变更在一个数据库事务中完成；推送、统计、相册和外部模型使用事务outbox在提交后执行。所有“可选增强失败”不能回滚已经确认的学习奖励。

## 2. 业务标识、权限与全局约束

### 2.1 标识与数值

所有业务ID为应用生成UUID。教材/题目/宠物包另有稳定业务key和不可变版本号。API字段snake_case；领域代码可使用内部命名，但序列化只有一套映射。时间戳为UTC ISO8601，学习日期用date，家庭时区使用IANA标识，服务端计算后冻结到学习日。

库存使用bigint最小单位，JSON对可能超过安全整数的通用计数字段使用十进制字符串。首版营养1单位等于1饱腹点；宠物状态使用0–10000整数，100单位等于界面1点。比例、时长、成本必须声明单位，禁止将浮点金币写入账本。媒体时长用毫秒，文件大小字节，模型成本以微货币单位及currency保存。

| 规则ID | 必须成立的约束 |
|---|---|
| R-01 | 访问资源的family/child从认证会话与资源归属核验，不信任请求body声明 |
| R-02 | 计划引用确切的已发布内容版本与scope；题目主要源片段属于scope |
| R-03 | 已计划、接触声明、训练参与、验证证据、掌握趋势分别存储 |
| R-04 | 客观答案由服务端按固定规则判定；公开题目不携带标准答案 |
| R-05 | 本次同题提示后成功不算新的独立掌握证据；能力不能互相冒充 |
| R-06 | 每日/每周资格稳定，换内容版本、规则版本、任务ID或设备都不新增资格 |
| R-07 | 任务确认、奖励发放、库存账本和快照在同事务提交 |
| R-08 | 消费先通过数据库事务，再播放动作；跳过动作不改变业务结果 |
| R-09 | 家长次日复核归原学习日；复核权限不受儿童开始挑战窗口限制 |
| R-10 | AI、场景包与动画事件不能直接写奖励、健康、死亡或开放时段 |
| R-11 | 未识别、内容故障、媒体失败与网络失败不记知识错误 |
| R-12 | 已发布payload不可变，修订新建版本；退役状态可独立变化 |
| R-13 | 旧设备迟到提交和旧快照不覆盖新租约、新修订号 |
| R-14 | 断网可保存待同步证据，未确认库存不可消费 |
| R-15 | 默认陪伴模式安全托管；系统停机不触发不可逆生命后果 |
| R-16 | 自动素材构建可重建、可检测、可停止，不依赖隐藏手工资产 |
| R-17 | 客户端没有正确率、余额、时钟和宠物状态的最终决定权 |
| R-18 | 删除题目或修正错误不追扣孩子已经获得的学习物品 |

### 2.2 权限模型

账号只用于家长/管理员身份；孩子是家庭内的独立学习主体，儿童设备会话固定child_id。成年人通过家庭成员关系获得owner/parent/content_editor权限。owner可管理家庭和其他成人；parent可编排、复核和照护；content_editor可处理教材和候选题，发布可由owner/parent授权。首个家庭可一人兼任。

儿童入口通过家长授权设备或家长登录后切换获得受限会话，不要求孩子真实邮箱。家长入口必须重新验证成人身份或使用短时step-up授权；隐藏按钮或一道简单算术题不能保护管理接口。

| 资源/命令 | owner | parent | content_editor | child | TV伴侣 |
|---|---|---|---|---|---|
| 家庭与成人成员 | 管理 | 只读基础 | 无 | 无 | 无 |
| 孩子档案与时间策略 | 管理 | 管理 | 无 | 读自己的显示字段 | 仅本配对孩子 |
| 教材草稿/候选题 | 管理 | 管理 | 管理授权库 | 仅已发布学习范围 | 仅当前题 |
| 内容发布与撤回 | 可 | 可 | 需显式权限 | 无 | 无 |
| 周计划与请假 | 可 | 可 | 无 | 只读/受限选择顺序 | 只读当前 |
| 口语与过期证据复核 | 可 | 可 | 无 | 录制自己的音频 | 仅当前授权录音上传 |
| 学习提交 | 可诊断不发孩子奖 | 同左 | 无 | 本人任务 | 指定题授权命令 |
| 发奖/赠物/冲正 | 系统或管理命令 | 受控赠物 | 无 | 无 | 无 |
| 喂食与装扮 | 可 | 可 | 无 | 自己拥有的物品 | 白名单命令 |
| 原始录音、导出、删除 | 可 | 按家庭设置 | 无 | 仅本人当前回放 | 无列表权限 |

数据库RLS作为第二道家庭隔离。每次事务通过SET LOCAL绑定经过认证的family_id，不用连接级永久SET；连接池复用不能泄漏上下文。应用角色无BYPASSRLS，表owner迁移角色与运行角色分开；worker逐任务按family执行。私有答案schema只向学习判分服务的数据库角色开放，不向Web资源服务开放。

### 2.3 安全会话

家长使用Argon2id密码摘要，参数在目标NAS校准；会话采用高熵随机opaque token，数据库只保存摘要，HttpOnly/Secure/SameSite=Lax Cookie，默认7日滑动有效、30日绝对上限。管理敏感操作要求近期认证；同源Origin检查＋CSRF token保护写操作。口语录音授权与对外模型授权分开。

配对码有效期5分钟、一次性、短码限次尝试，二维码可携带更高熵的随机挑战；创建TV会话后仍由家长设备确认家庭与孩子。服务端保存token摘要，配对设备可撤销，撤销后租约和WebSocket一并失效。首次部署无固定默认密码，用一次性引导凭据创建owner后关闭初始化入口。

### 2.4 错误和可重试语义

所有HTTP响应带request_id和server_time。错误对象包含code、message、retryable和可选field_errors；错误文本不回传SQL、密钥、完整原文或模型原始异常。校验失败400，未登录401，无权403，隐藏跨家庭资源时404，修订/租约/幂等冲突409，窗口或业务前提不满足422，频率/额度429，临时能力故障503。

客户端只对网络、408/429/5xx做有上限退避；409先拉取最新状态或按幂等键查询，不能盲目重新生成请求ID。系统错误不被转换为孩子答错。

## 3. 功能规格与交付阶段

P1为最小可用家庭闭环，P2补全宠物选择、生活场景与内容运维，P3加入电视壳、自动语音与智能陪伴，P4为真实生命等选择性扩展。接口可先预留P2/P3结构，未实现功能用feature flag明确不可用，不暴露假按钮。

功能清单附件每行包含功能ID、所属模块、功能、阶段、角色、输入/前提、输出/规则、验收点和主要operation_id。功能与接口不是一一对应：一个功能可由多个接口协作，一个查询可以服务多个页面。

首版必须覆盖身份、教材内容、导入与AI题库、周计划、外部学习声明、训练/验证、录音确认、奖励/背包、宠物喂养、自动素材生产和部署恢复。不能只实现漂亮小家，将教材和题目生产推到后续。

### 3.2 前端组件契约

QuestionRunner只接收公开题目DTO和当前会话模式，通过registry按question_type选择执行器。执行器必须提供render、validate_response_shape、serialize_draft、restore_draft、focus_first和dispose；不存在gradeCorrect客户端权威接口。

AudioCoordinator统一调度指令、题目音频、宠物声、TTS与录音。题目音频优先；录音前停止所有扬声器音源并等待短缓冲，结束后不自动播放答案。用户首次操作激活AudioContext，play失败显示重播入口。

PetStage接收只读PetSnapshot与已提交PetEvent，输出选择意图，如feed_requested或inspect_item；没有balance写入口。BehaviorController控制注意力、身体、面部与附属物多层动作；RendererPort有Pixi和静态实现。组件卸载取消ticker、监听与资源引用。

家长端复杂表格可筛选与批量处理，儿童端一屏一个主要行动。所有拖动同时支持点击/键盘替代，TV从同一题目使用不同布局，不把精细触摸当必需。儿童题意指令可朗读，目标词的朗读权限由所测能力决定。
