## 9. 接口、事件与集成契约

### 9.1 HTTP约定

所有业务接口前缀/api/v1，同源Cookie认证。GET无副作用；创建返回201，异步任务返回202＋job_id；更新返回资源和revision。列表使用cursor＋limit（默认20、最大100），不承诺offset在并发更新时稳定。写命令发送Idempotency-Key，修改已有聚合发送expected_revision；服务端也返回ETag供缓存校验。

成功响应统一为data、request_id、server_time和可选next_cursor。列表data.items。private答案、source_quotes里的标准答案以及内部评分说明不通过儿童查询返回；家长预览必须是独立受权路径。

附件OpenAPI定义每个operation_id、权限、阶段、请求/响应schema和错误码。大型媒体走二进制上传端点，不把base64塞进普通JSON。资源查询默认按会话family/child范围过滤，不允许普通用户请求任意family_id来切换家庭。

### 9.2 核心接口示例

```json
{
  "task_id": "40000000-0000-4000-8000-000000000001",
  "mode": "verification",
  "presentation": "home",
  "capability_profile_id": "40000000-0000-4000-8000-000000000002",
  "expected_task_revision": 3
}
```

创建session成功返回session_id、revision、lease_epoch、lease_expires_at、finish_deadline、form_version和公开items。提交answer包含challenge_item_id、response、expected_revision、lease_epoch和client_event_id；response按题型使用option_id、pairs、tokens、gaps或media_asset_id，禁止传correct/score。

```json
{
  "challenge_item_id": "40000000-0000-4000-8000-000000000003",
  "response": {"option_id": "o2"},
  "expected_revision": 1,
  "lease_epoch": 1,
  "client_event_id": "40000000-0000-4000-8000-000000000004"
}
```

终结验证接口只提交会话revision和租约，服务端按已保存attempt/review计算结果。返回completion_status、missing_requirements、review_request_ids和grant_receipts；不能客户端发送“本轮3/4正确”直接领取。

喂食请求只含item_id、requested_units（十进制整数字符串）与expected_revision，返回consumed_units、remaining_units、pet_snapshot、pet_event_id和receipt。宠物事件不是新的发奖授权。

### 9.3 主要错误码

| code | HTTP | 客户端处理 |
|---|---|---|
| AUTH_REQUIRED / SESSION_REVOKED | 401 | 回到设备授权或成人登录，不清除待同步草稿 |
| RESOURCE_NOT_FOUND | 404 | 隐藏跨家庭资源，显示不可用 |
| REVISION_CONFLICT | 409 | 拉最新资源，保留本地编辑并选择合并 |
| LEASE_STALE | 409 | 停止旧设备写入，显示已转移到其他设备 |
| IDEMPOTENCY_PAYLOAD_CONFLICT | 409 | 开发诊断，不能重试相同key不同内容 |
| WINDOW_NOT_OPEN / START_CUTOFF | 422 | 展示下一窗口或家长补做路径 |
| SUBMISSION_LATE | 422 | 保存待复核证据，不能标准时通过 |
| CONTENT_COVERAGE_MISSING / QUESTION_RETIRED | 422 | 同目标替换/待补题，不标孩子错误 |
| MEDIA_NOT_FINALIZED / RECORDING_UNREADABLE | 422 | finalize或重录/家长帮助 |
| REQUIREMENT_UNMET | 422 | 指向缺少能力的短补救项 |
| PET_FULL / SPECIES_INCOMPATIBLE | 422 | 不扣库存，说明原因 |
| INVENTORY_INSUFFICIENT | 422 | 刷新余额并保持物品选择 |
| AI_BUDGET_EXCEEDED | 429 | 停止新生成，已有题库可用 |
| CAPABILITY_UNAVAILABLE | 503 | 降级/人工路径，不作知识判错 |

### 9.4 领域事件

事件包含event_id、event_type、event_version、family_id、aggregate_type/id/revision、occurred_at、causation_id、correlation_id和payload。payload只含必要引用与公开摘要，录音和完整教材不放outbox正文。消费者以consumer_name＋event_id去重，重试失败写dead_letter并保留诊断。

| 事件 | 事务内产生点 | 消费者 | 业务唯一策略 |
|---|---|---|---|
| content.release.published.v1 | 正式发布提交 | 缓存失效、计划coverage刷新 | release_id/version |
| content.question.retired.v1 | 撤回题版本 | 受影响会话提示、证据修订队列 | question_version_id＋retirement_id |
| learning.exposure.recorded.v1 | 接触声明保存 | 复习候选索引 | exposure_id |
| learning.task.completed.v1 | 任务完成与grant同事务 | 学习观察、回忆、通知 | task_occurrence_id |
| learning.evidence.recorded.v1 | 有效attempt/review | mastery与复习卡 | evidence_id＋聚合器版本 |

| pet.care.committed.v1 | 喂食/照护事务 | 动作提示、成长日、回忆 | pet_event_id |

## 10. 离线、设备租约与多端同步

### 10.1 权威数据和本地存储

服务端拥有计划、题目版本、开放窗口、证据、库存和宠物状态。IndexedDB只存程序缓存、已下载公开题目、草稿、录音临时块、pending_operations和同步cursor。私有答案不离线下发，P1离线作答只能显示已保存/待确认，不自动给分发粮。

离线操作字段：client_event_id、operation、aggregate_id、lease_epoch、expected_revision、payload_hash、payload、local_created_at和sync_state。local_created_at用于提示，不证明准时。网络恢复先拉session/lease，再顺序发送；同session按事件序号发送，冲突后暂停剩余队列，不能乱序盲重试。

页面前台、online事件和用户点击可触发同步；online不等于NAS真的可达，API成功才显示联网。缓存驱逐可能丢失未同步记录，因此明显展示仅本机保存状态；大录音优先立即上传，不承诺浏览器后台永不丢数据。

### 10.2 会话租约

创建验证时写lease_owner_device、lease_epoch=1、expires_at，默认90秒租约，活跃前台每30秒续期。租约过期不等于新设备自动覆盖；用户选择接管后服务端锁session，epoch＋1，返回最新form与revision。旧设备即使仍在窗口内，其旧epoch提交也返回LEASE_STALE。

HTTP请求幂等、client_event_id唯一与lease_epoch分别处理重试、事件重复和旧拥有者问题，不能只用一个UUID解决所有并发。跨设备读取的pet/reward快照携带server_revision，客户端只接收较新修订。

### 10.3 电视与录音伴侣

TV用D-pad选择、确认、返回和播放/暂停；题型不要求拖拽、hover或精确点击。FocusManager保存focus_key图、默认焦点、弹窗焦点陷阱与返回栈；列表更新后按稳定key恢复，不能跳到页面最上方。

手机/iPad经短时配对加入特定家庭/孩子/会话，权限只允许获取当前oral item、上传对应录音和提交已授权响应。TV仍是主会话拥有者；伴侣命令由服务端绑定同一租约epoch，不能自行替换题单。断线重连拉当前状态，旧命令不能作用于下一题。

WebSocket只传消息command_id、session_id、lease_epoch、expected_revision和受限payload，服务端回ack/new_revision。初版可轮询，P3再用WebSocket改善同步；两种使用相同领域接口。

### 10.4 设备能力矩阵

设备注册上报浏览器/系统版本、WebGL能力、maxTextureSize、录音MIME候选、音频解码、触摸/键盘/方向键、存储估计及prefers-reduced-motion。客户端报告用于优化，服务端不将其视为安全凭证。

P1以真实家中iPad的Safari与主屏PWA为基线，推荐iPadOS17及以上；更低系统需单独实测。TV需明确型号、系统与WebView版本，缺WebGL时使用静态宠物，DOM题目仍可用。缺麦克风走伴侣/人工，不能把识别点选记作口语证据。

## 11. 后台任务、文件与发布一致性

### 11.1 任务执行

background_jobs字段包括job_type、status、attempts、max_attempts、available_at、lease_owner、lease_expires_at、input_ref、result_ref、progress、error_code、dedupe_key。状态queued→running→succeeded；可重试错误转retry_wait，终止为failed/cancelled。获取使用FOR UPDATE SKIP LOCKED，执行长任务前释放数据库事务；心跳续租，提交结果时再验证租约。

轻量worker默认并发2，家庭AI生成并发1，OCR/ASR默认独立worker。重复执行依赖业务唯一键，lease只防大多数并发不保证一次执行。作业输入是不可变版本ID，取消只阻止未提交下一阶段；已发布结果不会因取消撤销。

### 11.2 文件生命周期

媒体状态uploading→staged→validated→finalized→retired/deleted。上传先写临时随机目录，校验大小/MIME/hash/解码与权限，再原子rename到内容寻址目录，数据库finalize记录。文件与数据库无法同事务，采用阶段状态和可重试finalizer；孤儿文件定时清理，不能在DB已引用前立即删临时文件。

私有媒体经认证API或短时受控URL访问，缓存private；宠物公共资源可以immutable长缓存，教材和录音不自动公开。下载响应防内容嗅探，HTML/SVG按隔离策略处理，未经净化的文件仅附件下载。

单次默认限制：图片10MiB、音频10MiB、文档50MiB、ZIP100MiB/解压500MiB/2000文件；管理员可调但服务端强制上限。资源内容摘要可用于去重，但跨家庭不暴露文件是否存在，不能通过hash探测其他家庭资料。

### 11.3 内容与资源发布

发布物包含不可变manifest、源/题版本集合、质量报告引用与兼容能力。先构建临时版本并核对所有引用，再数据库事务写release、绑定题版本并切active指针；缓存通过outbox失效。失败继续旧版本，不让半成品被儿童端加载。

活跃计划引用版本不自动迁移；坏题退役是紧急可见状态，进行中session在下一提交/恢复检查时阻断该项并启动同目标替代，不篡改原attempt。API兼容当前和上一客户端协议版本；service worker新版本等到一轮挑战结束再提示激活。

## 12. 部署、运维与数据保护

### 12.1 容器拓扑

默认api-web、worker、postgres三个逻辑服务；api-web提供静态前端/API/受控媒体，worker可与API共用镜像但不同启动命令。HTTPS使用NAS现有反代；无现有能力可加网关。文档解析/模型服务是compose可选profile，素材构建在开发电脑或独立构建环境，不在NAS儿童运行服务内执行任意AI脚本。

应用端口仅供反代/内网访问，数据库不映射公网。非root运行、只读根文件系统、单独临时目录和持久卷，health与readiness区分进程活着和数据库/媒体可用。数据库镜像固定PostgreSQL16兼容版本，禁止自动追latest。

持久卷分数据库、media、packages、backups与配置。API和worker只写所需目录；媒体下载路径由服务端ID解析，不能接受客户端任意本地路径。环境示例只含占位符与变量说明，真实凭据通过NAS secret/env注入，不进入设计包、日志和浏览器。

### 12.2 HTTPS与初始化向导

向导检查域名解析、证书完整信任链、iPad实际地址访问、麦克风授权/回放/保存、持久卷写入、备份路径和时区。真实域名＋DNS-01签发＋内网DNS可避免公开应用端口；DNS凭据最小权限，证书续期有到期告警。

首个owner创建后录入家庭时区、孩子能力、设备和语音授权，再导入一个自编样例包完成试题和喂食自检。不使用固定admin/admin默认账户，不把生产健康检查误当业务验收。

### 12.3 备份与恢复

默认每日一次PostgreSQL一致性dump，记录schema_version、应用镜像digest、媒体manifest与文件摘要，所有被dump引用的媒体在备份完成前不被GC。备份文件原子写完并校验后标成功；加密密钥由家长独立保管，不与备份同目录明文保存。

初始目标RPO≤24小时、RTO≤60分钟，均需目标NAS实演校准。恢复先到新目录/新数据库，核对表数、资格与库存对账、媒体存在、样例孩子与宠物，再切服务入口。失败保留原数据，不直接覆盖生产卷。PWA未同步草稿不在NAS备份承诺范围内。

升级前备份；先做向后兼容迁移，再发布API/Web，再清理旧字段。破坏性迁移需维护窗口和明确恢复方案；回退不只是换回镜像，还需匹配schema和资源版本。

### 12.4 删除与保留

原始孩子录音默认30天（可调），复核完成后可早删；正在复核的音频设置短延长并提示家长，不能无限自动续期。对外模型传输前家长按能力授权，默认不上传整段学习历史。转写、证据与录音不同保留策略，删除音频不伪装删除所有证据。

家庭删除任务先撤销会话、停止新作业、标记purging，按依赖顺序清理私有文件与业务表，账本在专用维护角色下整体清除，写无个人明细的删除凭据。备份按约定最大保留期淘汰，恢复旧备份后重放删除清单，防已删除家庭重新出现。

### 12.5 可观察性与资源目标

日志包含request_id/job_id/family匿名标识、operation、耗时、错误code和trace_id；不记录密码、token、孩子原音、完整教材和标准答案。模型审计只保存受控产物/引用，不把凭据与整个prompt上下文倾倒到日志。

指标：普通API p95目标300ms（LAN、数据库热盘），已缓存触控反馈100ms，场景稳定30fps为最低目标，冷启动磁盘唤醒单列；测试基线一个家庭3台设备、5个孩子、1万源片段、2万题版本。2GB可用内存作为基础部署试测起点，4GB更从容；OCR/ASR内存另算。上述为验收目标而非已测结果。

运维面板显示备份新鲜度、磁盘、任务积压、AI额度、坏题/媒体错误、证书到期、数据库迁移版本与对账。磁盘不足时先停大文件导入/AI生成，已有学习只读和状态查询尽量可用；数据库写失败时不得显示虚假完成。

## 13. 测试、验收与开发拆分

### 13.1 测试层级

纯函数测试覆盖时间窗口、答案规范化、scope筛选、必需能力、奖励分配、喂食余粮、状态时间积分和复习排序。数据库集成测试覆盖家庭/孩子复合FK、RLS、append-only、发布冻结、同资格多设备重复提交、余额并发和事务回滚。API测试验证鉴权、错误码、幂等hash、租约和公开DTO无答案。浏览器测试验证学习主流程、草稿恢复、家长表单与静态回退。

真实iPad测试必须覆盖Safari与主屏PWA、拒绝/撤销麦克风、锁屏/切后台、格式探测、蓝牙耳机、存储不足和HTTPS证书。TV用纯D-pad完成选择、连线替代、返回、配对断线与恢复。桌面模拟不是这些能力的通过证据。

### 13.4 尚需实测或配置的参数

家庭NAS型号/架构、iPadOS与TV型号、当前教材版本/实际文件、每天可承受用时、模型服务与预算、宠物风格通过样片确定。默认值已经给出，缺少这些参数不阻止内核开发，但不得将未测兼容和识别效果标为完成。

真实生命模式具体周期、自动发音评测阈值、应用商店发布和跨家庭内容分享为后续独立决策。对应feature flag默认关闭，数据结构保留扩展点，开发验收不将占位字段算成功能完成。
