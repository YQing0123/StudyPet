## 4. 周计划、学习日与时间策略

### 4.1 周计划状态与编译

WeeklyPlan为一个孩子某家庭周的稳定容器；PlanRevision保存草稿与发布内容，修改后新建修订。状态draft→validating→validated→published；校验失败回draft并附问题；旧发布修订转superseded，不删除已执行任务。

编译输入包括教材版本/片段、任务目标、能力前提、日期、开放时段、训练/验证蓝图、每日预算和奖励策略版本。编译输出LearningDay、TaskOccurrence、TaskScope、TaskRequirement和RewardEntitlement。发布是数据库事务，不在事务中调用LLM或解析文件。

| 编译检查 | 阻断条件 | 可修复方式 |
|---|---|---|
| 教材可用 | 源版本未发布/已退役、源片段缺失 | 更新未开始范围、选择合法版本 |
| 范围闭合 | 目标源不在scope；上下文不足 | 增加上下文只读片，不自动扩测量范围 |
| 题库覆盖 | 必需能力无合格主项或补救项 | 后台补题、人工确认策略或减少目标 |
| 认知前提 | 不会拼写却必需手输；阅读能力不适合 | 换题型但保持被测能力，或改计划 |
| 设备 | 必需口语无麦克风且无人工路径 | 伴侣录音、家长确认或改目标 |
| 时间 | 预计验证＋必要收尾超过可用窗口 | 减少任务/目标，调整窗口 |
| 奖励 | 分配日粮超出40；同日期多个不兼容日资格 | 固定日预算并复用原资格 |
| 计划冲突 | 相同孩子/日期已有进行中范围被替换 | 保护已开始，新增下一日或新修订 |

首版只允许一周一个有效发布容器；重复发布相同revision返回原结果。发布所需题库snapshot和coverage报告有版本/hash，校验后发布时再次检查hash与退役标记，避免校验通过后题目已失效。

### 4.2 修改、请假和补做

未开始的任务可在新修订替换范围与时段；stable_slot继续沿用，不因新task UUID或内容版本变化重新分配奖励。已经开始的task保留原scope与要求；允许暂停后由家长显式选择结束原实例并安排后续，不覆盖作答快照。

当日已有成功资格不得再通过降低要求产生第二次奖励。新增任务默认optional且不增加日粮/建材额度；若未来任务从必需改为可选，显示对周目标影响，保留变更审计。一天部分必需任务完成可按冻结份额先获得对应食物；日建材仅在当日冻结必需集合完成后一次发放。

请假只对未开始未来学习日设置excused。周目标初始D为非休息计划日数，target=ceil(0.8×D)，D=5时4；D=0不能领奖。批准请假后的未来D可调整，目标修订保留原因；已获得周奖励不回收，不再发第二份。补做关联原learning_day_id和稳定资格，记录completed_at真实时间与makeup授权，不在补做当天复制一份。

任务因坏题无法验证使用blocked_content，不算孩子未完成。系统可以保留周履约评估为待处理，家长选择替代题或免除此目标；免除记录不生成能力掌握证据。

### 4.3 时段判定

每个LearningDay冻结family_timezone与本地日期；发布时将本地时间映射为UTC open_at、last_start_at、close_at和finish_deadline。默认19:00开放、19:25最晚开始、19:30常规结束、19:35收尾，实际日期与时区必须一起保存。P1不跨午夜设置窗口；旅行时区变更下一学习日生效。

```text
can_start(now, day, task):
  authenticated child owns task
  day not excused; task not completed/cancelled/blocked
  open_at <= server_now < last_start_at
  estimated_min_round_ms <= finish_deadline - now
  capability and published_question_coverage satisfied
can_submit(now, session):
  matching lease_epoch and active task revision
  now <= finish_deadline OR valid parent makeup/review authorization
```

last_start_at为排他的截止点，避免等于19:25时两端理解不同；页面显示按同一服务端参数。已开始录音在close_at后可收尾至finish_deadline；达到finish_deadline只保存草稿/录音，不强行声称失败。迟交进入late_review，不自动标准时，家长可确认学习完成但late标记保留。

静态查看、挑战开始、必要照护、自由装扮分别授权。默认自由互动预算180秒，在已确认日任务后解锁；必要饮水/托管不因预算耗尽被锁。客户端计时仅做展示，服务端心跳聚合日互动预算，无法替代系统级屏幕使用时间。

## 5. 学习会话、题单与判分

### 5.1 外部学习与接触声明

孩子进入任务可查看外部书/课位置，点击去学习只记录开始事件。回到应用选择实际学过的scope子集，服务端检查不得超过计划范围，写StudyExposure与ExposureSlice。未确认部分留待学；不自动减少必需任务条件，不对尚未接触范围启动强制验证。

历史学习导入由家长勾选书课，保存source=parent_import、declared_at和日期精度（known_day/approximate/unknown）。历史声明可进入复习候选，不补发历史物品。家长可安排短诊断，诊断证据与历史声明分开。

### 5.2 会话状态

训练session与验证session都持有不可变scope与题单。mode为training、verification或diagnostic；presentation为home、park、hospital，不把医院当第四种评分模式。

| 状态 | 允许事件 | 结果 |
|---|---|---|
| created | preload_success/preload_failed | ready或blocked_content |
| ready | start | active，发租约与服务端截止 |
| active | answer/hint/save/record/transfer | 保持active并增revision，或转待处理 |
| submitting | commit_success/timeout | awaiting_review/completed/needs_support；超时查幂等结果 |
| awaiting_review | adult_approve/needs_help | completed或needs_support，不能重复提交同复核结果 |
| late_review | adult_accept/reject/resume | 完成（保留late）或待帮助 |
| needs_support | create_remediation/pause | 同目标补救题或paused |
| paused | resume（窗口内或有授权） | active，不换题单版本 |
| completed | read_receipt | 终态；同请求重放返回原结果 |
| blocked_content | replace_invalid_item/parent_override | 新form版本或待处理，原尝试留存 |
| cancelled/expired | archive/parent_review | 不自动发奖，允许保存但不重复写active |

服务端拥有会话业务状态，XState负责前端交互镜像与宠物行为，不自行推断已奖励。challenge_items保存冻结的question_version、公开payload快照、private评分引用、目标要求、选项顺序和变式家族。恢复会话仍得到同一表单，随机打乱只在创建表单时执行。

### 5.3 组题算法

输入为task_scope、task_requirements、actual_exposure、device_capabilities、question_bank_release和seed。先排除退役题、媒体不可用题、能力不符题、源文范围不符题，再按未暴露family、目标覆盖和短用时排序。必需目标先各挑一个，再在预算内补题；同主目标通常最多2项。

使用固定seed的Fisher–Yates确保重放稳定，但seed不作为安全凭证。题单中正确项ID稳定且不包含correct/right等语义。主源片段必须属于本轮范围；context_slice只补阅读语境，不因此把该上下文全部加入测量目标。

优先顺序：必需目标缺证据→最近独立错误且到期→长期未查且适合目标。暖身题可先用识别，再到表达，但不能因暖身总分替代必需朗读。当前家庭数据少，不做题目区分度/IRT自动校准。

训练已经看过答案的family在同日验证中降级为assisted，不计算独立掌握。若必须使用同family，页面可以完成任务，但证据写answer_exposed，之后安排隔日变式；不能仅交换选项顺序清除暴露记录。

题不足时按“同目标合格变式→改变非目标操作→家长确认→待补题”处理；不按总分临时取消必需能力，不抽未学内容凑题。

### 5.4 响应与评分契约

| question_type | 响应 | 服务端评分 |
|---|---|---|
| audio_to_picture / word_to_picture / picture_to_word / sentence_choice / reading_choice | option_id | 是否属于冻结allowed_option_ids且匹配答案集合 |
| cloze_choice | gap_id→option_id映射 | 每空独立判定，缺空标incomplete，整体按蓝图要求 |
| cloze_text | gap_id→text映射 | 按每空normalization与accepted_answers，不拼接所有空模糊比较 |
| matching | left_id→right_id完整映射 | 校验左右元素集合和一对一限制，逐对比较；不接受客户端mistakes=0 |
| word_order | token_id序列 | 校验token多重集合恰好相等，再比较允许序列；重复词用不同token实例 |
| oral_reading | media_asset_id＋recording_metadata | 音频finalized且属于当前孩子/题，进入人工或校准评估 |
| retell | media_asset_id或家长现场确认 | 保存rubric与来源，开放表达不以简单ASR词匹配当全对 |

Grader为纯函数grade(question_private, response, grading_profile)→verdict。verdict包含correct、incorrect、partial、incomplete、unrecognized或pending_review，以及per_target、normalization_applied、reason_codes和评分版本。接口不接受client_correct、score或mistakes作为可信输入。

答案文本先NFC、统一允许的引号、trim与连续空格；大小写、末尾标点、缩写和英美拼写是否等价由题目profile控制。拼写目标禁止全局编辑距离容错；tree≠three，bag≠bags，不能因相差一字母自动通过。句意训练可以接受已明确列出的It is/It's，词形学习则按目标保留差异。评分规则不由LLM生成任意正则并执行。

词序题与填空题按已有词块或允许答案确定性判分，不把“与标准句字符串不相同”一律当错。训练时立即解释与可重试，验证时本轮最终提交前不向其他未答题泄露整套答案；反馈可以按题单策略延后到一轮结束。

### 5.5 验证蓝图与补救

默认全客观表单4项，threshold=3；混合表单3客观＋1朗读，客观threshold=2，朗读required。两种都要求每个task_requirement存在可接受成功证据，不能用总分越过未测目标。

首轮未达标可生成短补救表单，仅覆盖缺少的必需要求。补救表单保留parent_session_id、requirement_id和既有暴露；一次任务只产生一个最终TaskCompletion。两次主动尝试后持续显示求助，不强迫重复整套。补救达到任务完成可以发相同基础资源，独立掌握统计仍排除受提示结果。

### 5.6 口语与复核

P1录音格式运行时探测，最长单词10秒、句子30秒、复述60秒，可由策略调整；上传上限10MiB，真实MIME与时长服务端解码复检。录音上传采用init→上传→finalize；仅finalized、未过期且与孩子/会话/题绑定的音频可以评分，用户不能随意引用别人的asset ID。

家长复核显示教材目标、示范音频、孩子录音与rubric，动作approve、needs_help、unrecognized。approve写parent_confirmed证据；机器原判定不可被原地改写，新增人工判定与supersedes关系。次日复核按原学习日结算，缺失音频时可明确选择现场确认，并保留不同来源。

ASR增强只判断听到的内容，不输出虚假的发音准确率。静音、噪声、网络/设备故障转unrecognized，不进入知识错误分母。专业评测接入后必须以家庭童声样本测试误拒/误放，仍保留人工路径；不以声纹确认孩子身份。

### 5.7 证据与掌握聚合

学习证据由attempt和review产生，唯一键至少包含source_event_id＋objective_id＋skill＋modality。保存independence=independent/prompted/answer_exposed/parent_confirmed、verdict、content_version、发生时间、源题与撤回状态。

初始掌握标签：unseen（无接触）、introduced（有接触无有效验证）、practicing（有帮助或失败）、emerging（一次独立成功）、stable（至少两个不同学习日、至少一个有效变式的独立成功）。这些为产品观察标签，不声称统计概率。一次独立失败使相应能力进入review_due，不删除过去成功；标签与复习到期是并行字段。

同日同family重做不增加独立成功日数。阅读理解题只更新所测理解目标，不把源文里每个词都记成会读；诊断通过只更新诊断所测能力。无效题版本撤回后重算受影响聚合，不改发奖历史。

复习规则P1：下一个计划学习日、约3天、约7天；due_at与scheduled_learning_date分开。排序可参考弱项优先，但每轮受每日预算和scope约束，不能因为题不够就从所有已完成课随机填满。
